# Shader 渲染练习

Unity ShaderLab 渲染练习集合，覆盖常用光照模型、纹理映射与顶点动画。

## 内容

- 光照：PerVertexDiffuse / PerPixelDiffuse / PerVertexPhong / PerPixelPhong / BlinnPhong
- 纹理：SingleTexture / NormalTexture / BumpTexture / MaskTexture / RampTexture
- 顶点动画与效果：Billboard（公告牌）/ SequenceAnimation（序列帧）/ ScrollingBackground（滚动背景）/ FlowingRiver（流动河流）

## 说明

基础渲染练习，覆盖逐顶点 / 逐像素光照、法线 / 遮罩 / 渐变纹理、透明与顶点动画等主题。
